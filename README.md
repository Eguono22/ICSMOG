# ICSMOG
Intelligent computer systems for monitoring an organization are advanced setups that use technologies like artificial intelligence (AI), machine learning (ML), big data analytics, and automation to keep track of various aspects of organizational performance, security, and operations.

## Modules

| # | Module | Classes |
|---|--------|---------|
| 1 | **Network & Cybersecurity Monitoring** (`src/cybersecurity`) | `IntrusionDetectionSystem`, `IntrusionPreventionSystem`, `SecurityInformationEventManagement` |
| 2 | **Business Performance Monitoring** (`src/business`) | `EnterpriseResourcePlanning`, `BusinessIntelligence` |
| 3 | **Environmental & Infrastructure Monitoring** (`src/infrastructure`) | `IoTSensor`, `IoTSensorNetwork`, `BuildingManagementSystem` |
| 4 | **Employee & Workflow Monitoring** (`src/workforce`) | `WorkforceAnalytics`, `WorkflowManagement` |
| 5 | **Predictive Maintenance & Operational Monitoring** (`src/maintenance`) | `PredictiveMaintenanceSystem`, `SCADASystem` |
| 6 | **Customer & Market Monitoring** (`src/customer`) | `CustomerRelationshipManagement`, `SentimentAnalyzer` |

## Running

```bash
python main.py
```
